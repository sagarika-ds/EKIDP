🚀 EKIDP – Enterprise Knowledge Intelligence & Decision Platform

An AI-powered enterprise platform that prevents organizational knowledge loss and accelerates executive decision-making by combining document intelligence, a knowledge graph, retrieval-augmented search (RAG) and predictive analytics.

📌 Overview

EKIDP helps organizations preserve critical knowledge, intelligently search enterprise documents, analyze relationships between employees, projects, and technologies, and generate data-driven insights for better decision-making.



🛠️ Tech Stack
Backend: Java 21, Spring Boot, Spring Security
Frontend: HTML, CSS, JavaScript, Chart.js, D3.js
Database: PostgreSQL
Graph Database: Neo4j
Vector Database: ChromaDB
NLP & ML: Python, spaCy, NLTK, scikit-learn
Document Processing: Apache Tika
Infrastructure: Docker, Docker Compose

📂 Project Structure
backend/ – Spring Boot backend services
nlp-service/ – Python NLP and ML services
docker/ – Docker Compose configuration for databases

🚀 Getting Started
Start the required services using Docker Compose.
Run the Spring Boot backend.
Start the Python NLP service.
Open the application in your browser.

🎯 Learning Outcomes

This project demonstrates enterprise application development using Spring Boot, NLP with spaCy, Knowledge Graphs (Neo4j), Retrieval-Augmented Generation (RAG), Machine Learning, REST APIs, and Docker-based deployment.
